# magicsih Homebrew tap

macOS apps published by [magicsih](https://github.com/magicsih).

```sh
brew tap magicsih/tap
brew install --cask chda
brew install --cask leaflit
brew install --cask callpath
```

- [chda](https://github.com/magicsih/chda): a terminal with a Git worktree side panel and agent status board.
- [Callpath](https://github.com/magicsih/callpath): Java와 Kotlin 코드를 호출 흐름으로 읽는 리뷰 앱. macOS 13 이상에서 Apple Silicon과 Intel을 지원합니다.
- [Leaflit](https://github.com/magicsih/leaflit): a read-first Markdown viewer with explicit Source editing, offline diagrams and math, for Apple Silicon on macOS 14 or later.

Casks point to versioned GitHub release archives and verify their SHA-256 checksums. Leaflit 0.3.0 is a preview; its runtime verification currently covers Apple M3 on macOS 26.6.2. This personal tap is separate from the official Homebrew cask repository.
