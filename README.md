# magicsih Homebrew tap

macOS apps published by [magicsih](https://github.com/magicsih).

```sh
brew tap magicsih/tap
brew install --cask chda
brew install --cask leaflit
```

- [chda](https://github.com/magicsih/chda): a terminal with a Git worktree side panel and agent status board.
- [Leaflit](https://github.com/magicsih/leaflit): a read-only Markdown viewer with offline diagrams and math, for Apple Silicon on macOS 14 or later.

Casks point to versioned GitHub release archives and verify their SHA-256 checksums. Leaflit's first release is a preview; its runtime verification currently covers Apple M3 on macOS 26.6.2. This personal tap is separate from the official Homebrew cask repository.
